\section{Task Overview}
% Item 2: Task title and overview, significance, what makes it challenging
[Describe the project at a high level. State the task title, what problem you are solving,
why it matters, and what makes it non-trivial/challenging.]
We are creating a program to catalogue various percusive instruments based on their waveform. 
Many musicians find it very difficult to catalogue instruments because many instruments do not have physical identifiers on them.


This task is challenging because: the raw waveform must be converted with a Fourier transformation into time--frequency features such as a spectrogram.

\section{Task Definition}
% Item 3: type of data, classification/regression/generation, number of classes, single/multi-label

The data we are working with is an audio .wav file. This is a single-label, multi-class classification task with 8 classes, one per instrument in the dataset: flute, oboe, cor anglais (english horn), clarinet, bass clarinet, bassoon, contrabassoon, saxophone, french horn, trombone, trumpet, tuba, banjo, cello, db bass, guitar, mandolin, viola, violin. Each clip is one note by one instrument. The input features describe the sond of the note: fundamanetal frequency, timbre, harmonics, resonance, dynamics 
We have 39 classes (various percussive instruments). We have multipule features: Fundamental frequencies, Timbre, Resonance, Harmonics, noisiness/dynamics

\section{Problem Description and Impact}
% Item 4: Describe the problem, its impact on the real world, and why it is challenging
[Explain the problem in more depth, its real-world significance/impact, and elaborate on
the technical or practical challenges involved.]
Suppose a recording of a composition uses a certain wind/string instrument, and we want to find the same instrument again. Being able to say what instrument a sound came from based on how it sounds makes it easier to search.

The challenges are: (1) audio analysis requires knowledge of signal-processing, we will be using Fourier transofms; (2) the same instrument sounds different across pitches, dynamics and articulation, so the model must not just learn "pitch" or "loudness" as a shortcut; (3) many instruments uner the same family share very similar timbre; (4) because the recordings are really clean this may not transfer to real world recordings.
